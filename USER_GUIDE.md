# 📘 Recruiter Guide — Hi! PARIS Career Fair App

🤗 Welcome! This one-page guide shows you how to find candidates, open CVs, track follow-ups, and stay in sync with your colleagues. 

⏱️ Reading time: about 3 minutes.

---

## 🗺️ The workflow at a glance

**🔐 Sign in → 🔎 Find a candidate → 📄 Open CV → ✅ Mark status → 💾 Save → 📊 Check progress → 🔄 Refresh often**

---

## 1. 🔐 Sign in

1. Open **your sponsor's** app link.
2. Enter your **username** and **password**.
3. Click **🔐 Sign in**.

Wrong details show *"Invalid username or password."* Check that you opened the right sponsor app. To leave, use the `↪ Log out` control in the page header, especially on shared devices.

---

## 2. 🔎 Find a candidate and open the CV

In **🔎 Find a candidate**, click the search box and type a first or last name. Capitals and accents don't matter (*chloe* finds *Chloé*). Pick the person from the list.

A candidate card appears with three buttons:

| Button | What it does |
|---|---|
| **📄 Open CV** | Opens the PDF in a new browser tab. Allow pop-ups if nothing opens. |
| **👁 Mark viewed** / **Unmark viewed** | Toggles the *Viewed* flag |
| **✉️ Mark contacted** / **Unmark contacted** | Toggles the *Contacted* flag |

> If you see **📄 No CV**, the candidate has no CV file linked. Tell the organisers.
>
> Two candidates with the same name could be different people: please check the CV before marking anything.

---

## 3. ✅ Update the overview table

**👥 Candidates Overview** lists candidates with four checkboxes:

| Column | Meaning |
|---|---|
| **Viewed** | You looked at the profile |
| **Interested** | Worth following up |
| **Saved** | CV kept |
| **Contacted** | Candidate has been contacted |

✅ Tick or untick directly in the table. 
⚠️ Names are read-only.
🔍 If a candidate is selected, the table shows only that person; 🧼 clear the selection to see everyone. 
🙌 Agree with your team on what each flag means, so colleagues read them the same way.

---

## 4. 💾 Save your changes

Edits save **automatically** about one second after you stop clicking. You can also press **💾 Save now**. Watch the status line under the table:

| Status | Meaning |
|---|---|
| ✅ All changes saved | Nothing waiting |
| ⏳ Changes pending — saving in … | Autosave is about to run |
| 💾 Saving… | Save in progress |
| ❌ Save failed. Your changes are retained. | Try **Save now**; keep the tab open |

⚠️ Wait for ✅ before closing the tab or leaving.

You can also force the saving by clicking on the button `💾 Save now`. 

---

## 5. 🔄 Refresh: the most important button

You and your colleagues each have **your own copy** of the list in your browser. When a colleague saves a change, **your screen does not necessarily update right away**.

Press **🔄 Refresh** to download the latest shared list and merge it with your own work.

### When to press it

- 🟢 **When you start** working
- 🟢 **Before** you decide anything based on a colleague's status (e.g. "has this person been contacted?")
- 🟢 When a colleague says *"I just updated the list"*
- 🟢 If something looks out of date
- 🟢 **Before you finish** your session

### How the merge works

| What happened | Result |
|---|---|
| You and a colleague edited **different candidates** | ✅ both changes kept |
| Same candidate, **different checkboxes** | ✅ both kept |
| Same checkbox, **same** new value | ✅ no problem |
| Same checkbox, **different** values | ⚠️ a conflict message appears and **your value is kept** |

### Rules of thumb

1. **Save first, then refresh.** Refresh is not a save button. Wait for ✅ All changes saved.
2. **Split the work.** If two of you work the same list at once, agree who handles which candidates (e.g. by alphabet or by role).
3. **Check after a conflict.** If you see *"conflict(s) detected… Resolved in favor of local values"*, look at the final checkbox state and talk to your colleague.
4. **Warning banner?** *"⚠️ Another recruiter made changes while you were editing"* means their changes will be merged in after you save. Save, then Refresh.

---

## 6. 📊 Statistics and filtering

At the bottom, **📊 Candidates tracking** gives you a summary line:

> 👥 **N candidates** · 👁️ viewed · 👍 interested · 🔖 CVs saved · ✉️ contacted

Use the **Filter candidates** dropdown to show only **All**, **Viewed**, **Interested**, **CVs saved** or **Contacted**. Changing the filter clears the selected candidate and keeps any edits you made. This is handy for building your follow-up list, e.g. *Interested* but not yet *Contacted*. Counts reflect your latest synced data, so Refresh first for a team-wide picture.

---

## 7. 📅 Doodle

The **📅 Doodle** button opens your sponsor's booking board, where you see which students booked a 5-minute slot. Students book through the QR code, and you use this button to check the bookings.

---

## 🆘 Quick fixes

| Problem | Try this |
|---|---|
| CV does not open | Allow pop-ups; on iPhone, use Chrome |
| A colleague's edits are missing | Wait for ✅ saved, then **🔄 Refresh** |
| Save failed | Press **💾 Save now**; keep the tab open; tell the organisers if it repeats |
| Can't sign in | Check you're on your own sponsor's app and retype the password |
